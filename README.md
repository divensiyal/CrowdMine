\# CrowdMine



CrowdMine is a collaborative data collection and dataset generation platform.



\## Backend



The backend is built with:



\- FastAPI

\- SQLAlchemy

\- PostgreSQL

\- JWT Authentication



\## Data Processing Modules



The backend currently includes:



1\. Contribution Management

2\. File Upload

3\. Data Validation

4\. Compatibility Engine

5\. Data Quality

6\. Data Standardization

7\. Duplicate Detection

8\. Dataset Integration



\## Running the Backend



```bash

cd backend

uvicorn app.main:app --reload
